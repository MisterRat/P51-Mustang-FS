# P-51D Mustang Flight Simulator

A single-file, offline flight simulator for the P-51D Mustang, built on three.js (inlined). Runs in any modern browser on desktop, tablet or phone.

**Play:** enable GitHub Pages (Settings > Pages > Deploy from branch > `main` / root), then open `https://<your-username>.github.io/<repo-name>/`.

Press `I` in the game (or open the pause menu) for the controls, operations and About pages. Keyboard, gamepad and phone sensors are supported; Hardcore realism options are all optional.
